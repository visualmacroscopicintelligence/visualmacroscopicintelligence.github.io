# Visual Macroscopic Intelligence Site

This folder contains a GitHub Pages-ready research hub for Visual Macroscopic Intelligence.

Files:

- `index.html`: VMI topic homepage / research hub. It intentionally does not include Google Scholar `citation_*` paper metadata.
- `papers/visual-macroscopic-intelligence/index.html`: Google Scholar-friendly full-text HTML page for the survey, with `citation_*` metadata, figures, references, and links to PDF/BibTeX. The supplementary material is kept in the PDF only.
- `papers/visual-macroscopic-intelligence/visual-macroscopic-intelligence-survey.pdf`: merged main manuscript and supplementary material.
- `papers/visual-macroscopic-intelligence/visual-macroscopic-intelligence-survey.bib`: BibTeX citation.
- `papers/visual-macroscopic-intelligence/figs/`: figures used by the survey HTML full text.
- `robots.txt`: allows crawler access.
- `sitemap.xml`: sitemap for Google Search Console.
- `.nojekyll`: disables Jekyll processing on GitHub Pages.

Assumed public URLs:

```text
https://zhiqiangyuan.github.io/multiimage_survey/
https://zhiqiangyuan.github.io/multiimage_survey/papers/visual-macroscopic-intelligence/
```

If the final GitHub Pages URL is different, update the absolute URLs in `index.html`, `papers/visual-macroscopic-intelligence/index.html`, `robots.txt`, `sitemap.xml`, and `papers/visual-macroscopic-intelligence/visual-macroscopic-intelligence-survey.bib` before publishing.
