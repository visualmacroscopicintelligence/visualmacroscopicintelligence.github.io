Fine-grained Fragment Retrieval in Multi-modal Long-form Dialogues

Hanbo Bi1, Zhiqiang Yuan1, Chongyang Li1, Qiwei Yan1, Zexi Jia1, Jiapei Zhang1, Xiaoyue Duan1, Yingchao Feng1, Jinchao Zhang1,*, and Jie Zhou1
1Pattern Recognition Center, WeChat AI, Tencent Inc, Shenzhen, China
Submitted to IJCV: June 3, 2026
Retrieval Dialogue Multi-modal Reinforcement Learning Long-context
Download PDF arXiv BibTeX

Abstract

With the widespread adoption of multi-modal communication platforms, long-form dialogues interleaving text and images have become increasingly common. Users often need to retrieve coherent dialogue fragments related to specific topics, rather than isolated utterances. We propose Fine-grained Fragment Retrieval (FFR), which locates semantically relevant multi-utterance, multi-image fragments in multi-modal long-form dialogues. We explore two settings: (1) FFR within Single-Dialogue, retrieving fragments from a given dialogue; and (2) FFR within Dialogue Corpus, retrieving from a large-scale corpus for open-domain scenarios. For (1), we introduce F2RVLM, a generation-based retrieval model trained with reinforcement learning, using multi-objective rewards and difficulty-aware curriculum sampling to enhance fragment coherence. For (2), we develop FFRS, a two-stage system combining offline fragment-level indexing with online retrieval. Specifically, each dialogue is decomposed into minimal semantic fragments encoded by a Fragment Embedding Model (FEM) into a vector database; at inference, FEM rapidly recalls Top-K candidates, and F2RVLM performs fine-grained reasoning to identify the most relevant sub-content. To support FFR, we construct MLDR, the longest multi-modal dialogue retrieval dataset to date, and a WeChat-based real-world test set. Experiments on both benchmarks demonstrate that F2RVLM and FFRS consistently achieve superior performance across single-dialogue and corpus-level FFR.

Keywords

fine-grained fragment retrieval, multimodal dialogue, multimodal retrieval, vision language model, reinforcement learning, long-form dialogue

Method

FFR addresses two retrieval settings in multimodal long-form dialogues:

  • Single-Dialogue FFR — Given a query, retrieve relevant fragments from a single dialogue. We propose F2RVLM, a generation-based retrieval model trained with GRPO reinforcement learning, using multi-objective rewards (relevance + coherence) and difficulty-aware curriculum sampling.
  • Corpus-level FFR — Retrieve fragments from a large-scale dialogue corpus. We develop FFRS, a two-stage system: (1) offline fragment-level indexing via Fragment Embedding Model (FEM) stored in a vector database; (2) online retrieval where FEM rapidly recalls Top-K candidates and F2RVLM performs fine-grained reasoning to identify the most relevant sub-content.

Datasets

  • MLDR — The longest multi-modal dialogue retrieval dataset to date, supporting both single-dialogue and corpus-level FFR evaluation.
  • WeChat Real-world Test Set — A production-scale test set collected from WeChat multi-modal communication scenarios.

Key Results

Experiments on MLDR and the WeChat real-world test set demonstrate that F2RVLM and FFRS consistently achieve superior performance across single-dialogue and corpus-level FFR, outperforming baseline retrieval models in both relevance and fragment coherence.
